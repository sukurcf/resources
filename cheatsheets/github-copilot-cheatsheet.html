Copilot Architecture & Flow

What: How your prompt flows through Copilot — context is gathered, routed via a proxy to the AI model, filtered for safety, and returned as a response.
Key Stages
  • Context gathering — workspace files, open tabs, selections, instructions
  • Pre-model filters — responsible AI, content exclusion
  • Proxy service — routes to chosen model, applies policies
  • AI model — user picks model or auto-select (10% discount)
  • Post-model filters — duplicate code detection, safety checks
Installation
ext install GitHub.copilot ext install GitHub.copilot-chat
💡 Data handling depends on your plan, surface, model host, and settings. Business/Enterprise customer data is not used to train AI models; individual-plan interactions may be used for training unless you opt out. Do not treat this conceptual diagram as a contractual data-flow guarantee.
Use Cases
Debug unexpected output — understand why Copilot gave a wrong answer (check if context was gathered correctly)
Explain to stakeholders — describe the documented data-flow, plan, provider, and policy boundaries (security/compliance reviews)

Next Edit Suggestions (NES)

What: Predicts your next edit based on recent changes, not just cursor position. Jumps you to the right location and suggests the change — great for repetitive multi-location refactors.
How It Works
  • Monitors your editing patterns across files
  • Suggests edits at locations you haven't navigated to yet
  • Shows arrow indicator → jump to suggested edit
  • Tab to navigate to edit, Tab again to accept
  • Enable with github.copilot.nextEditSuggestions.enabled
Why Use It
  • Rename variables across multiple locations
  • Apply consistent pattern changes
  • Add missing imports after using a new API
Use Cases
Rename userId → accountId — change one occurrence, NES finds and fixes the rest across files
Add error handling — wrap one function in try/catch, NES suggests the same for similar functions
📚 Sources: VS Code Docs — Next Edit Suggestions

Inline Chat

What: Chat with GitHub Copilot directly inside your editor or terminal without switching to the sidebar. Get targeted code edits, command generation, and image-to-code conversion in context; image support depends on the selected model and policy.
In Editor
  • ⌘I (Mac) / Ctrl+I (Win) — open inline chat
  • Select code first for targeted edits
  • Supports context vars & model selection
  • Preview diff before accepting
In Terminal
  • ⌘I in terminal — generate commands
  • Copilot understands shell context
  • Run (⌘Enter) or Insert (⌥Enter) after reviewing the command
  • Generates and explains terminal commands
Vision Input
  • Attach images when the selected model supports vision
  • UI mockups → code generation
Use Cases
Refactor selected code — select a function, ⌘I → "Extract this into a custom hook" (targeted in-place edit)
Generate shell commands — ⌘I in terminal → "Find all .log files larger than 100MB and delete them"

MCP — Model Context Protocol

What: An open standard that connects GitHub Copilot to external tools and services. MCP servers can expose tools, resources, prompts, and interactive apps, but support depends on the client and execution surface.
VS Code: .vscode/mcp.json
{ "servers": { "github": { "type": "http", "url": "https://api.githubcopilot.com/mcp" }, "playwright": { "type": "stdio", "command": "npx", "args": ["-y", "@microsoft/mcp-server-playwright"] } } }
MCP Capabilities
CapabilityDescription
ToolsExecute operations (file, DB, API)
ResourcesRead-only context (Add Context → MCP Resources)
PromptsTemplates via /server.prompt
MCP AppsInteractive UI in chat
SamplingServer-initiated model calls
ElicitationServer asks user for input
Key Servers
github-mcp-serverGitHub APIs
PlaywrightBrowser automation
SandboxmacOS/Linux: sandboxEnabled
⚠️ Only use MCP servers from trusted sources. Review configs before starting.

Use Cases

Copilot on GitHub.com

What: GitHub.com Copilot features include Copilot cloud agent, Copilot code review, pull-request summaries, issue workflows, and CodeQL Autofix. Cloud agent (formerly Copilot coding agent) is distinct from Agent mode in an IDE and works in an ephemeral GitHub Actions-powered environment. GitHub plans to relaunch Copilot Chat on github.com, Copilot Chat in GitHub Mobile, and cloud agent as one experience and one policy no earlier than 28 Sep 2026.
Coding Agent
  • Delegate tasks from GitHub.com, supported IDE entry points, or Copilot CLI
  • Use /delegate in Copilot CLI or delegate from an issue, PR comment, or supported chat surface
  • Creates a branch and works in an ephemeral, firewalled GitHub Actions environment
  • Consumes AI credits and GitHub Actions minutes
  • Follow up with steering comments
  • Maximum execution time is 59 minutes; one task is limited to one repository, branch, and PR
PR & Issue Features
  • PR Summary — auto-generate descriptions
  • Code Review — assign Copilot as reviewer
  • Issue helper — create/update issues with Copilot
  • Autofix — code scanning security fixes
Customize Agent Environment
  • Use copilot-setup-steps.yml (GitHub Actions workflow)
  • MCP servers for cloud agent
  • Preinstall dependencies, choose supported runners, and configure secrets/variables
  • Deep research, planning, and iteration before a PR are available on GitHub.com; other integrations may create a PR directly
Use Cases
Delegate a feature — /delegate + link to GitHub issue → agent creates a branch, implements, and opens a PR
Auto-review PRs — assign Copilot as reviewer on every PR → catches bugs, style issues, and security flaws
📚 Sources: GitHub Docs — Copilot Cloud Agent · Code Review

Cloud-Agent Environment Security

AI-Credit Cost Controls

What: One GitHub AI Credit equals $0.01 USD. Cost depends on the model and input, output, and cached-token usage. Control spend with model selection, context and reasoning choices, session limits, budgets, and Actions-minute governance.
Individual Controls
  • Paid plans receive a 10% model-cost discount when using Auto model selection in Copilot Chat, CLI, the GitHub Copilot app, or cloud agent.
  • Use lighter models for simple edits and higher-capability models for complex reasoning. Long context and higher reasoning use more credits.
  • Copilot CLI supports a per-response soft limit with --max-ai-credits or /limits set max-ai-credits VALUE.
  • Included credits reset monthly and do not carry over. Additional usage requires a budget and can be capped.
  • Individual user budgets can have an expiration date (since 1 Sep 2026); budget increase requests are generally available (since 16 Sep 2026).

ControlScope
User-level budgetHard stop for one user's total AI-credit consumption across shared-pool and metered phases.

Enterprise budgetCaps enterprise-wide metered charges after the pool is exhausted; it is not the total monthly bill.
